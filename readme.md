# La Prosperidad

## Descripción

La Prosperidad es un proyecto desarrollado como parte de un proceso de aprendizaje en desarrollo web. Su objetivo es ofrecer una página web con un diseño moderno, organizado y fácil de usar, aplicando buenas prácticas de HTML, CSS y JavaScript.

## Características

* Diseño responsive.
* Interfaz amigable e intuitiva.
* Navegación sencilla.
* Código organizado y fácil de mantener.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/rodrigoandresrivas397-ux/la-prosperidad-.git
```

2. Entra a la carpeta del proyecto:

```bash
cd la-prosperidad-
```

3. Abre el archivo `index.html` en tu navegador o ejecuta el proyecto con la extensión **Live Server** de Visual Studio Code.
